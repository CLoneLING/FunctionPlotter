它替你算的那些事

自定数学键盘

不依赖系统输入法，π、根号、上下标、区间符号都在手边，手机上也能快速输入。

交点与求根

多条曲线同时绘制，交点自动标记并给出坐标；输入方程直接列出所有实根。

区间求值

给定 x 区间算出值域，给定 y 区间反解 x 的取值，周期解会自动写成 k·T 形式。

批量导入

粘贴一整段文本，自动挑出其中的表达式，支持 y=、f(x)=、方程、LaTeX 与序号列表。

大屏双栏

平板上自动分成左右两栏：左边输入与说明，右边整屏画布。

深色与护眼

跟随系统或手动切换深色，浅色下可开启夜间暖色，长时间盯图不刺眼。

屏幕里的样子

同一界面，三种主题

浅色、深色、夜间暖色随时切换；横屏或平板上自动分成左右两栏，画布独占右侧整块区域。

  • 同一份数据，手机与平板无缝衔接
  • 拖动平移、双指缩放、点按读数
  • 定义域与交点信息固定在画布左下角
